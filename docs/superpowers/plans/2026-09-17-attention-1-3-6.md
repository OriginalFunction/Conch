# Attention control 1.3.6 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop every agent answering every question, by making an answer impossible to compose before the floor is held and a mention stop meaning "your turn".

**Architecture:** Three mechanical changes. A withdrawal is modelled as a
tombstone intent (`IntentKind::Drop`) that supersedes a queued intent through
the gossip path intents already use, so no new wire message or consensus rule is
needed. `say` learns the room's head before it queues and refuses to speak if a
speech committed while it waited, keeping the grant so the agent can decide
again. `events::flatten` classifies each take as a `mention` for at most one
agent and a `cc` for everyone else it names.

**Tech Stack:** Rust workspace (`conch-core`, `conchd`, `conch-mcp`, `conch`),
tokio, serde_json, ed25519-dalek. Markdown skill file. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-09-17-attention-design.md`

## Global Constraints

- Areas 1 and 2 of the spec only. Area 3 (listen economics) and Area 4
  (presence and supervisor) are out of scope for this plan.
- A withdrawal must survive gossip and leader change; it may not rely on a new
  `SwarmMsg` variant or a new consensus rule.
- `say` keeps the grant when it declines to speak. It must never leave a grant
  held without telling the caller it holds one.
- Yielding empty is a success, never an error.
- Only one agent may receive a `mention` from a take. Every other named agent
  receives `cc`.
- `@all` and `@everyone` stay a `mention` only when the take's author is a
  `human:` mouth.
- Do not worry about backwards compatibility of on-disk or on-wire shapes.
- Mac line endings. No attribution trailers in commit messages.
- The gate is `cargo fmt --all -- --check`, `cargo clippy --workspace
  --all-targets --locked -- -D warnings`, `cargo test --workspace --locked`.

### Task 1: A dropped intent never reaches the head of the queue

**Files:**

```rust
fn a_dropped_intent_supersedes_its_wait_and_leaves_the_queue_to_the_next_mouth() {

    let node = NodeId::from_bytes(key.verifying_key().to_bytes());
    let room = RoomId::from_bytes([3; 32]);
    let state = state(room, vec![node], None);
    let mut engine = FloorEngine::new(node);

    assert!(engine
        .upsert_intent(&state, intent(&key, room, "agent:first", 1, 100))
        .unwrap());

        .upsert_intent(&state, intent(&key, room, "agent:second", 2, 200))
        .unwrap());

        engine.queue_head(&state, 300).unwrap().agent.as_str(),
        "agent:first"

    // queued intent, and the tombstone is never grantable.

        "agent:second"
    );

    assert!(engine
        .upsert_intent(&state, intent(&key, room, "agent:first", 4, 400))
        .unwrap());
    assert_eq!(
        engine.queue_head(&state, 500).unwrap().agent.as_str(),

    );
}
```

- [ ] **Step 4: Stop a tombstone poisoning the next hand**

In `crates/conchd/src/tcp.rs`, `queue_intent` reuses an existing intent's id,
timestamp and kind when the caller is waiting. A tombstone must not be reused
that way, or the mouth stays withdrawn forever. Change the lookup so a `Drop`
intent is treated as absent:

```rust
        let existing = floor
            .engine
            .lock()
            .expect("floor lock is not poisoned")
            .intents()
            .find(|intent| {
                intent.agent == agent
                    && intent.node == node
                    && !replay.chain.consumed_intents.contains(&intent.id)
            })
            .cloned();
        // A withdrawal is a tombstone, so a new hand must mint a fresh intent
        // with a later timestamp rather than inherit the one it cancels.
        let superseded = existing
            .as_ref()
            .filter(|intent| intent.kind == IntentKind::Drop)
            .map(|intent| intent.ts);
        let existing = existing.filter(|intent| intent.kind != IntentKind::Drop);
```

Then, in the `(id, ts, kind)` match, give the fresh intent a timestamp later
than the tombstone it replaces:

```rust
            _ => (
                Hash32::from_bytes(random::<[u8; 32]>()),
                superseded.map_or(now, |ts| now.max(ts.saturating_add(1))),
                kind,
            ),
```

- [ ] **Step 5: Add the handler**

In `crates/conchd/src/tcp.rs`, add the method beside `client_raise_hand`:

```rust
    /// Cancel this mouth's queued hand by superseding it with a tombstone. The
    /// tombstone gossips and persists exactly like the intent it replaces, so a
    /// withdrawal survives a leader change instead of being re-advertised.
    async fn client_withdraw(&self, agent: AgentId, room: RoomId) -> Result<Value, DaemonError> {
        let node = self.node_id();
        let queued = {
            let floor = self.floor(room)?;
            let replay = self.replay(room)?;
            let engine = floor.engine.lock().expect("floor lock is not poisoned");
            engine
                .intents()
                .any(|intent| {
                    intent.agent == agent
                        && intent.node == node
                        && intent.kind != IntentKind::Drop
                        && !replay.chain.consumed_intents.contains(&intent.id)
                })
        };
        if !queued {
            return Ok(json!({ "withdrawn": false }));
        }
        self.queue_intent(room, agent, IntentKind::Drop).await?;
        Ok(json!({ "withdrawn": true }))
    }
```

```rust
    /// The room's committed head height, or 0 when nothing has committed.
    async fn room_head(&self, room: RoomId) -> Result<u64, (String, String)> {
        let status = self.ask(ClientRequest::Status { room: Some(room) }).await?;
        Ok(status["head_n"].as_u64().unwrap_or(0))
    }

    /// Committed takes above `after_n` that this mouth did not author, in the
    /// same event shape `listen` returns.
    async fn speeches_since(
        &self,
        room: RoomId,
        after_n: u64,
        you: &Mouth,
    ) -> Result<Vec<Value>, (String, String)> {
        let page = self
            .ask(ClientRequest::History {
                room,
                from_n: after_n.saturating_add(1),
                follow: false,
            })
            .await?;
        let records = page["scenes"].as_array().cloned().unwrap_or_default();
        let mine = serde_json::to_value(you).expect("mouth is serializable");
        let speeches: Vec<Value> = records
            .into_iter()
            .filter(|record| {
                record["scene"]["body"]["type"] == json!("speech")
                    && record.get("author").is_some_and(|author| *author != mine)
            })
            .collect();
        Ok(events::flatten(&speeches, you))
    }
```

```rust
/// How a take addresses one agent.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Address {
    /// This take asks this agent to answer.
    Mention,
    /// This take names this agent without asking it to answer.
    Cc,
    /// This take does not name this agent.
    None,
}

/// Every `@handle` in the order it appears, lowercased and without the `@`.
/// A handle must start the text or follow whitespace or punctuation, so an
/// email address is not a handle.
pub fn mentioned_handles(text: &str) -> Vec<String> {
    let lower = text.to_ascii_lowercase();
    let bytes = lower.as_bytes();
    let mut handles = Vec::new();
    for (at, _) in lower.match_indices('@') {
        let preceded_ok =
            at == 0 || bytes[at - 1].is_ascii_whitespace() || bytes[at - 1].is_ascii_punctuation();
        if !preceded_ok {
            continue;
        }
        let handle: String = lower[at + 1..].chars().take_while(|c| is_id_char(*c)).collect();
        if !handle.is_empty() {
            handles.push(handle);
        }
    }
    handles
}

/// Only the first handle in a take is asked to answer. Everyone else it names
/// is copied, so one question draws one answer instead of four. A broadcast
/// stays a summons only when a person wrote it.
pub fn address(text: &str, agent: &AgentId, author_is_human: bool) -> Address {
    let full = agent.as_str().to_ascii_lowercase();
    let short = full.split_once(':').map(|(_, short)| short.to_owned());
    let is_me = |handle: &String| {
        *handle == full || short.as_deref().is_some_and(|short| handle == short)
    };
    let is_broadcast = |handle: &String| handle == "all" || handle == "everyone";
    let handles = mentioned_handles(text);
    if author_is_human && handles.iter().any(is_broadcast) {
        return Address::Mention;
    }
    match handles.first() {
        Some(first) if is_me(first) || is_broadcast(first) => Address::Mention,
        _ if handles.iter().any(|handle| is_me(handle) || is_broadcast(handle)) => Address::Cc,
        _ => Address::None,
    }
}
```
