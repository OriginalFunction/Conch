# Images in Conch — implementation plan (1.3.5)

**Spec:** `docs/superpowers/specs/2026-09-08-images-design.md`

**Goal:** serve committed blobs over HTTP, render a take's attachments in the
operator console, and let the operator attach images to a take.

**Scope:** layers 1 and 2 of the spec. Layer 3 (agent tools) is 1.3.6 and is not
part of this plan.

## Global constraints

- Only a blob a committed scene references is servable; the file name comes from
  that `BlobRef`.
- Sniff the content type from magic bytes. Never add `mime` to the chain schema.
- Only PNG, JPEG, GIF, and WebP are served inline. Everything else, SVG
  included, is `application/octet-stream` with `Content-Disposition: attachment`.
- Every blob response carries `X-Content-Type-Options: nosniff` and
  `Cache-Control: private, max-age=31536000, immutable`.
- The console uploads through the existing `put_blob` websocket handshake. No
  new upload endpoint.
- The gate is `cargo fmt --all -- --check`, `cargo clippy --workspace
  --all-targets --locked -- -D warnings`, `cargo test --workspace --locked`.

## Tasks

### Task 1 — locate a committed blob (`crates/conchd/src/tcp.rs`)

`Daemon::blob_ref(room, sha256) -> Result<Option<BlobRef>, DaemonError>` scans
the cached replay's history newest first for a `Body::Speech` whose `blobs`
contains the digest, through `with_replay` so no history is cloned.
`Daemon::read_blob(room, sha256) -> Result<Vec<u8>, DaemonError>` reads the
bytes through the room's store.

Test in `crates/conchd/tests/`: a committed speech with a blob resolves; an
unknown digest is `None`.

### Task 2 — sniffing and disposition (`crates/conchd/src/http.rs`)

`fn sniff_image(bytes: &[u8]) -> Option<&'static str>` for the four raster
formats. `fn content_disposition(inline: bool, name: &str) -> String` producing
`filename="..."` with control characters, quotes, backslashes and path
separators stripped, plus `filename*=UTF-8''<percent-encoded>`.

Unit tests: each magic number, a truncated header, a RIFF that is not WebP, an
SVG document, a name with a quote and a name with non-ASCII characters.

### Task 3 — the blob routes (`crates/conchd/src/http.rs`)

`GET /operator/rooms/{room}/blobs/{sha256}` authorized like
`operator_room_history`; `GET /blobs/{room}/{sha256}` authorized like
`get_history`. One shared handler: resolve the ref, read the bytes, verify
length and digest, build the response with the headers from the constraints.

Tests in `crates/conchd/tests/http.rs`: a PNG served inline with its type
through the operator route and through a trusted proxied origin; a text file
served as an octet-stream attachment; an unknown digest 404; the operator route
refused without the cookie; the public route refused without its bearer token.

### Task 4 — render attachments (`ui/index.html`, `ui/app.js`, `ui/app.css`)

An `.attachments` strip under `.take-text`, built from `body.blobs`: image
extensions become lazy thumbnails linking to the operator blob URL, everything
else becomes a download chip, and an `<img>` that fails to load swaps itself for
a chip. Clicking a thumbnail opens a dialog with the full image. Phone widths
cap a thumbnail at 240px tall.

Extend the embedded-UI test to assert the new markup ships.

### Task 5 — stage, resize, and upload (`ui/index.html`, `ui/app.js`, `ui/app.css`)

An Attach button, paste on the draft, and drop on the composer feed one staging
list rendered beside the draft with per-file removal and sizes. `resizeImage`
downscales an image longer than 2048px to JPEG q0.85 and leaves smaller PNGs
alone. `putBlob` sends the JSON frame then one binary message of a big-endian
u32 length and the bytes. Wrap and yield uploads every staged file, then speaks,
then yields, aborting before `speak` on a failed upload with the file named.

### Task 6 — release 1.3.5

Workspace version, README and `packaging/debian/apt/README.md` mentions, a
`packaging/debian/changelog` entry, the full gate, and a Playwright check at
1280 and 390 against a debug daemon holding a take with a PNG and a text file.
